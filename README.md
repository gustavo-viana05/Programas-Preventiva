# Programas Preventiva
Criei esse arquivo .bat que faz a instalação de alguns programas que uso em atendimento.
Facilita para ganhar tempo e não precisa ficar procurando em sites.
Apenas com um clique ele baixa e instala os programas.

Contém:
CrystalDewWorld.CrystalDiskInfo,
CrystalDewWorld.CrystalDiskMark,
CPUID.HWMonitor,
CPUID.CPU-Z,
AnyDesk
